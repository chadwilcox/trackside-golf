# Trackside Par 3

A 9-hole par-3 golf game based on the course at Trackside Golf, Mapleton, Maine.

Play: https://chadwilcox.github.io/trackside-golf/

On a phone, open the link and choose **Add to Home Screen**. Once it has loaded once, it works offline.

When you change any file, bump `VERSION` in `sw.js` so installed copies update.
